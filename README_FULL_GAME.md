# Operation: Perfect Date — Full Game V1

Integrated sequence:

1. NIC / NIBM
2. Simply Strawberries by Jagro
3. Vito Wood Fired Pizza
4. Scope Cinemas at CCC
5. Personal birthday finale

## Run
Replace `index.html`, `src/main.ts`, and `src/style.css` in the existing Babylon/Vite project. Keep the existing `public/assets` directory. Then run `npm run dev`.

Normal player: `/`
Debug editor: `/?editor=1`

Controls: tap/click/Space/Enter to advance, Esc or pause button to pause, Restart Game to restart from NIC.
